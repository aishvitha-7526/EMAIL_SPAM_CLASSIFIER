# Email Spam Classifier-CITS2755

## Project Overview
Email Spam Classifier is a Machine Learning project that classifies emails as **Spam** or **Not Spam (Ham)** using Natural Language Processing (NLP) and classification algorithms. It helps filter unwanted emails and improve email security.

## Objective
The main objective of this project is to automatically detect spam emails based on their content and classify them accurately.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Matplotlib

## Methodology
1. Collect and preprocess email data.
2. Clean and tokenize the text.
3. Convert text into numerical features using TF-IDF.
4. Train a Machine Learning model.
5. Predict whether an email is Spam or Ham.
6. Evaluate the model's performance.

## Features
- Email Text Preprocessing
- Spam Detection
- TF-IDF Vectorization
- Machine Learning Classification
- Model Evaluation

## Results
- Classifies emails as Spam or Ham.
- Reduces unwanted email messages.
- Improves email filtering efficiency.
